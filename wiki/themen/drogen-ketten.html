Drogen-Ketten (Spielmechanik)

Drogen sind ein optionaler Wirtschaftszweig (Mod iM7s Drug Running) – reine Spielmechanik: Anbau oder Labor, Verarbeitung an Stationen, Pressen zu Bricks.

  • Verkauf: Bricks kauft nur der Schwarzmarkt (Hassan).
  • Aufwand: Pflanzen brauchen Zeit und Platz, Labore brauchen Laborbedarf von Quinn.
  • 18+ Spielinhalt – keine Anleitung für die reale Welt.

🌿 Cannabis

Pflanzen im Zelt/Topf → Trocknen am Drying Rack → Trimmen → Abpacken → Brick an der Production Table.

🧪 Crystal

Labor-Station (Drug Lab) → Tray → Production Table → Brick. Laborbedarf gibt es bei Quinn.

💊 Pillen

Presse (Tisch) → Bündel → Brick an der Production Table.

🍃 Kokain

Pflanzen im Zelt → Trocknen → Chem-Fass → Bündel → Brick.

🌺 Opiate

Mohn im Zelt → Chem-Fass → Production Table → Brick (Pulver/Teer); Fentanyl direkt im Chem-Fass.

🎨 LSD

LSD-Lab mit Timer → fertige Bögen (zufälliges Motiv).

🍄 Pilze

Sporenspritze in Garten/Zelt → wachsen → ernten.

Drug chains (game mechanic)

Drugs are an optional economy branch (iM7s Drug Running mod) – pure game mechanic: growing or lab, processing at stations, pressing into bricks.

  • Selling: only the Black Market (Hassan) buys bricks.
  • Effort: plants need time and space, labs need lab supplies from Quinn.
  • 18+ game content – not a real-world guide.

🌿 Cannabis

Plant in tent/pot → dry on the drying rack → trim → bag → brick at the production table.

🧪 Crystal

Drug lab station → tray → production table → brick. Lab supplies are sold by Quinn.

💊 Pills

Press (table) → bundle → brick at the production table.

🍃 Cocaine

Plant in tent → dry → chem barrel → bundle → brick.

🌺 Opiates

Poppy in tent → chem barrel → production table → brick (powder/tar); fentanyl directly in the chem barrel.

🎨 LSD

LSD lab with timer → finished sheets (random motif).

🍄 Mushrooms

Spore syringe into garden/tent → grow → harvest.
