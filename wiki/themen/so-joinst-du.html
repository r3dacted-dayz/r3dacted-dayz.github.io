🔌 So joinst duHow to join

🔌 So kommst du auf R3DACTED – in 5 Schritten. Das Wichtigste: DZSA Launcher nutzen, dann passt die Mod-Liste automatisch.

🔌 How to join R3DACTED – 5 steps. Key point: use the DZSA Launcher, then the mod list matches automatically.

Beitreten

1 · Voraussetzungen

DayZ (Steam, nur PC, kein Crossplay), Steam muss laufen, Karte Nasdara (Badlands) – voraussichtlich wird das Badlands-DLC benötigt (noch nicht offiziell bestätigt), bis zu 60 Spieler. BattlEye ist Pflicht.

2 · Launcher

Lade den DZSA Launcher. Suche in der Serverliste nach „R3DACTED“ – der Eintrag heißt [DE/EN] R3DACTED PVPVE | Trader|Cars|Helis|BBP|Airdrop|Quest – und klicke Join. Der Launcher lädt alle Mods und sortiert sie richtig.

3 · Direktverbindung

Du kannst den Server auch direkt eintragen: 176.9.19.34 · Spielport 2302 · Query-Port 2303 (DayZ-Launcher → Direktverbindung, oder im DZSA „Server hinzufügen“).

4 · Passwort

🔑 Kein Passwort nötig – der Server ist offen. Alle Infos auch in #how-to-join und #server-info.

5 · Mods

Die komplette Liste mit Workshop-Links findest du im Beitrag Mod-Liste. Fehlt ein Mod oder hat er eine andere Version, kickt dich der Server. Hilfe: #support-ticket.

Neustarts

Der Server startet alle 4 Stunden neu (00, 04, 08, 12, 16, 20 Uhr). Kurz danach wieder verbinden.

Joining

1 · Requirements

DayZ (Steam, PC only, no crossplay), Steam must be running, map Nasdara (Badlands) – the Badlands DLC will probably be required (not officially confirmed yet), up to 60 players. BattlEye is required.

2 · Launcher

Get the DZSA Launcher. Search the server list for "R3DACTED" – the entry is called [DE/EN] R3DACTED PVPVE | Trader|Cars|Helis|BBP|Airdrop|Quest – and click Join. The launcher downloads all mods and orders them correctly.

3 · Direct connect

You can also add the server directly: 176.9.19.34 · game port 2302 · query port 2303 (DayZ launcher → Direct connect, or "Add server" in DZSA).

4 · Password

🔑 No password needed – the server is open. All info also in #how-to-join and #server-info.

5 · Mods

The full list with Workshop links is in the Mod list post. If a mod is missing or has a different version the server kicks you. Help: #support-ticket.

Restarts

The server restarts every 4 hours (00, 04, 08, 12, 16, 20). Reconnect a little later.

Häufige Fehlercodes

0x00040080 – „PBO beschädigt“?

Die Meldung im Spiel irritiert: meist fehlt ein Mod oder die Liste weicht vom Server ab. Lösung: Mod-Liste mit dem Beitrag vergleichen, alle Mods aktualisieren, im DZSA „Verify“. Über den DZSA Launcher beitreten.

0x00030074 – Mod-Mismatch

Ein Mod fehlt oder hat eine andere Version. Lösung: im Launcher alle Mods auf den neuesten Stand bringen und neu starten.

0x00040090 – PBO-Mismatch

Eine Mod-Datei ist beschädigt oder veraltet. Lösung: den betroffenen Mod neu herunterladen (abbestellen → neu abonnieren).

0x000400F0 – BattlEye

BattlEye hat dich gekickt oder läuft nicht. Lösung: Spiel über den Launcher mit BattlEye starten, Steam/Spiel neu starten, Antivirus prüfen.

0x0004006F – Verifizierung

Signaturprüfung schlägt fehl (Mod-Version/Schlüssel). Lösung: Mods aktualisieren, Client-Neustart.

Hängt beim Laden / Timeout

Steam und Launcher müssen laufen. Läuft gerade ein Neustart, kurz warten. Firewall/VPN prüfen.

Common error codes

0x00040080 – "PBO corrupted"?

The in-game message is misleading: usually a mod is missing or your list differs from the server. Fix: compare your mods with the post, update all mods, use "Verify" in DZSA. Join through the DZSA Launcher.

0x00030074 – mod mismatch

A mod is missing or has a different version. Fix: update all mods in the launcher and restart.

0x00040090 – PBO mismatch

A mod file is damaged or outdated. Fix: re-download the affected mod (unsubscribe → subscribe again).

0x000400F0 – BattlEye

BattlEye kicked you or is not running. Fix: start the game through the launcher with BattlEye, restart Steam/game, check your antivirus.

0x0004006F – verification

Signature check fails (mod version/key). Fix: update mods, restart the client.

Stuck loading / timeout

Steam and launcher must be running. If a restart is in progress, wait briefly. Check firewall/VPN.
